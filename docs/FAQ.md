# 常见问题

### 如何下载、试用和购买？

从 [GitHub Releases](https://github.com/Beritwu/weixin-sales-workbench/releases) 下载安装包，在 [产品主页](../README.md#试用与购买) 扫码添加微信，申请试用或购买登录密钥。价格、使用期限与服务内容由微信沟通确认。

### 需要什么电脑和微信版本？

使用 Windows 10/11 x64 和兼容的微信 4.x。0.2.13 安装包已包含 Node、PowerShell、.NET、WebView2、Python 等运行组件，安装在本应用目录中。准备好自己的微信客户端及模型网关，按首次使用引导连接即可。

### 只适合销售客户吗？

个人聊天同样适用。可以整理自己的表达习惯、聊天对象的情况和双方的关切，用笔记记录重要内容、用任务安排后续事项。商品、订单与售后模块按自己的使用场景选择。

### 三个聊天学习按钮分别做什么？

“获取微信聊天记录”读取本机文本；“生成人格”整理自己的表达习惯；“用户画像”整理所选聊天对象的情况。生成结果可以回看原文、修改和保存，再用于回复试答。

### 聊天记录读取到什么范围？

读取本机已保存的一对一文本，保留发送者、时间和来源。手机尚未同步到电脑的历史、群聊、图片及语音转写不属于当前聊天学习范围。每次总结选取所选范围最近 **160 条文本**。

### 首次聊天读取怎样设置？

登录自己的电脑微信，在首次使用页勾选本机读取确认，再点击“初始化本机聊天读取”。软件获取并校验本机消息库的读取密钥，保存到本机工作区，页面显示通过的消息库数量。已有自己的读取缓存时，也可以直接填写缓存文件路径。

读取密钥不上传，不随安装包分发。遇到初始化提示时，按页面检查微信登录状态、版本和进程权限，或联系支持协助。

### 生成人格需要训练或微调模型吗？

无需微调。工作台通过聊天样本、可编辑总结和对话上下文，让你配置的云端模型生成草稿。人工保存的总结会保留，再次生成时也会作为参考。

### 如何使用回复辅助和自动化？

先连接微信并配置模型，再从聊天学习、会话与助手中生成和调整草稿。自动回复默认关闭；需要使用自动化时，再配置对应目标、规则和运行开关。运行控制中可以人工接管或紧急停止。聊天学习里的“试答”只展示回复内容，不向微信联系人发送消息。

### 我的聊天数据保存在哪里？

聊天资料、业务记录和人工调整的总结保存在本机工作区。使用云端模型整理或试答时，参与该次生成的消息样本或上下文会发送到你配置的模型服务；模型连接测试只使用简短的连接提示。

### 登录密钥和模型网关密钥有什么区别？

登录密钥由分发者提供，用于进入工作台。模型网关密钥由你使用的模型服务提供，用于调用模型。保存网关密钥后，设置页会读取其状态，留空即可沿用，页面不回显明文。

### 登录密钥有效期怎么算？

提供 **1 天 / 1 年**两种签发选项，**从生成时开始计算固定到期时间**。到期后联系分发者获取新的登录密钥。当前采用本机离线时间校验，不包含机器码绑定和在线吊销。

### 怎么更新版本、更换电脑或重装？

更新前备份本地数据，关闭工作台后使用新安装包更新原目录。更换电脑或重装时，联系支持安排数据与配置迁移；在新电脑重新连接微信、配置模型并初始化该电脑的聊天读取。

### 可以用于团队吗？

工作台提供成员、角色和权限相关设置。标准密钥登录关联本地工作区账号；需要多成员部署和协作方案时，请联系支持沟通。

### 微信连接或读取出现问题怎么办？

先查看页面的账号、窗口和读取状态提示。联系支持时提供工作台版本、Windows 版本、微信版本及错误代码，便于定位配置或适配问题。

### 公开仓库里包含哪些内容？

公开仓库提供产品介绍、使用文档和安装包下载入口，开发源工程不在此发布。安装包包含运行所需脚本和资源。Releases 自动生成的 “Source code” 压缩包是展示仓库的文档，下载安装软件请选 `.exe` 文件。
