# 常见问题

### 软件免费吗？怎么下载试用？
安装包公开下载，实际使用需要登录密钥。试用、购买价格和服务范围，请在主页扫码加微信咨询。

### 为什么没有源代码？
这是商业软件的展示与分发仓库，公开的是商品介绍、文档和安装包，不是软件源工程。Releases 下的 Source code 仅打包本仓库文档。

### 只适合销售客户吗？
不是。聊天学习也面向普通聊天对象，可整理自己的表达习惯、对方的情况和双方的关切。销售管理模块可按需使用。

### 能读到手机上的全部微信记录吗？
不能作此承诺。当前聊天学习读取本机可用的一对一文本，受本机保存范围和读取器配置限制；不包含全部群聊或媒体历史。每次生成总结取所选范围最近160条文本。

### 是训练一个新模型吗？
不是。当前使用上下文、可编辑总结和模型调用来辅助回复，不做模型微调。

### 下载后就能自动回复吗？
不能直接这样理解。真实微信、模型、发送对象及规则需要配置和验证；当前预览版尚未完成全部自动回复发送闭环的验收。建议先核对草稿，再安排可控环境下的功能验证。

### 我的聊天会上传吗？
本地工作区保存业务和聊天资料；调用云端模型时，参与该次生成的消息或上下文会发送到配置的模型服务。安装前应确认自己的模型服务、用途和数据处理要求。

### 密钥有效期怎么算？
当前支持分发者生成1天或1年密钥，从签发时开始计算固定到期时间，不是首次激活才开始。到期后需联系分发者。当前没有机器码绑定和在线吊销。

### 更换电脑或重装怎么办？
先备份数据并联系支持确认配置迁移。历史读取与模型连接可能需要重新设置；不要把其他电脑的数据库解密缓存直接当作通用配置使用。

### 用于多成员协作吗？
系统有成员、角色与权限相关实现，但当前简化密钥登录默认关联本地工作区账号。多成员部署应先咨询支持，不能把个人安装当作已部署好的多人服务。

### 微信版本不兼容怎么办？
把软件、Windows和微信版本发给支持，先核对适配情况。原生控制能力取决于客户端与桌面环境，不承诺支持所有历史和未来版本。
