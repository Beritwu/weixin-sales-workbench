# 功能全览

微信销售工作台将微信会话、联系人资料、AI 回复辅助、跟进任务和交易记录放在一个 Windows 工作空间中。个人聊天可以直接使用聊天学习、资料和笔记；业务往来则可以继续关联商品、订单与售后。

## 聊天学习：三个按钮，整理自己的聊天上下文

| 功能 | 使用方式 |
| --- | --- |
| **获取微信聊天记录** | 读取本机已保存的一对一文本，保留发言人、时间和消息来源，显示读取数量。 |
| **生成人格** | 根据本人的发言整理语气、常用措辞与回应习惯，形成可编辑的表达总结。 |
| **用户画像** | 选择聊天对象，整理对方的情况、双方关切、本人顾虑与决定，以及计划和待确认事项。 |

生成后可以回看引用的原文，修改并保存总结。再次生成会保留人工保存的版本；试答使用已保存的人格与画像，生成回复草稿供查看和调整。**试答不会发送微信消息。**

每次总结采用所选范围最近 **160 条文本**，通过上下文和可编辑资料辅助云端模型回复，无需模型微调。聊天学习范围为本机的一对一文本，手机未同步历史、群聊及图片、语音转写不在该范围内。

## 日常工作与联系人资料

| 模块 | 功能 |
| --- | --- |
| 今日工作 | 集中查看待回复、到期任务、人工接管、发送异常、待收款/发货与售后事项。 |
| 客户与联系人 | 新建资料、昵称搜索、阶段筛选、资料卡、最近互动、负责人及协作者管理、CSV 导入导出。 |
| 会话与助手 | 查看会话和上下文，生成 AI 草稿、人工编辑、转人工处理、发送前确认与状态查看。 |

| 笔记 | 创建编辑、分类查找、发布版本，关联联系人、商品或订单，设置私人或团队可见范围。 |

## 微信连接与运行管理

软件通过自带原生控制器发现微信账号、关联窗口，并提供托盘恢复操作。工作台与微信保持独立窗口；微信侧原生贴边标签保留消息监听、消息管理和工具集，工作台侧边栏管理资料、任务、会话和设置。

自动化页面集中管理欢迎语、关键词、定时任务等规则配置。运行控制提供自动回复开关、紧急停止、人工接管和连接诊断。自动回复默认关闭，聊天学习与试答独立使用。

## 首次使用与模型设置

首次使用按三个步骤完成连接：

1. **连接微信**：打开并登录电脑微信，发现账号。只有一个账号时自动连接；多个账号首次连接时选择使用对象。界面分别显示账号发现与窗口关联状态。
2. **配置模型**：填写自己的本机模型网关地址与访问密钥，获取模型列表后选择使用。保存后动态加载，并可通过“测试模型回复”查看模型实际返回的文本。
3. **初始化聊天读取**：确认读取自己的本机微信后，点击初始化。软件校验消息库读取密钥并保存在本机，显示通过的消息库数量；也支持使用自己的已有读取缓存。

网关密钥保存后可继续沿用，设置页面不回显明文。模型连接测试使用简短提示；聊天整理和试答会将相应消息样本或上下文发送到你配置的模型服务。

## 数据与授权管理

- 本地数据备份和恢复副本校验。
- 模型用量、预算与表达规则管理。
- 本地工作区账号、角色与权限设置；团队部署可联系支持安排。
- 单密钥登录，提供 **1 天 / 1 年**签发选项，有效期从生成时开始计算。

## 运行环境

适用于 **Windows 10/11 x64** 和兼容的 **微信 4.x**。安装包内置 Node、PowerShell、.NET、固定版 WebView2、Python 及聊天读取依赖，安装在应用目录中。微信客户端和模型网关由使用者准备。

下载、安装和连接步骤见 [安装指南](GETTING-STARTED.md)，试用与购买请在 [产品主页](../README.md#试用与购买) 扫码联系。
