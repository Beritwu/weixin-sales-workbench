## 聊天学习与回复辅助

1. **获取微信聊天记录**：读取本机可用的一对一文本，保留发言人和时间等来源信息。
2. **生成人格**：从本人的话整理表达习惯与回应方式，不把对方发言当成本人风格。
3. **用户画像**：按聊天对象整理情况、双方关切、本人顾虑与决定、计划和待确认信息。
4. **总结调整**：查看生成所用原文，修改并保存；重新生成不会直接覆盖人工保存的总结。
5. **试答**：使用保存的人格/画像辅助生成回复草稿，不在这个流程中自动发送。

当前限制：本机一对一文本、每次最近160条样本；不等于手机完整历史，不包含完整群聊/图片/语音导入。需要 Python 与可用读取器配置。提取和生成仍可能出错，需核对谁说的、何时说的以及计划/完成状态。当前没有模型微调。

## 微信控制与自动化

工作台与微信保持独立窗口，原生标签提供消息监听、消息管理、工具集入口；有账号发现、窗口关联和托盘恢复等相关控制逻辑。

规则配置包含欢迎语、标签/关键词、定时任务、转发与执行优先级。运行控制提供自动回复开关、紧急停止、人工接管、连接诊断与状态核对。

**实际微信操作依赖原生控制器、客户端版本和桌面环境。当前尚未完整验收自动回复发送闭环，也没有逐项验收所有自动化副作用。** 不承诺任意目标、任意消息类型都能自动发送。

### 扩展入口：按依赖与适配情况使用

以下功能有界面、配置或适配入口，但不能据此认定全部可在新电脑直接运行：

- 好友列表和缓存、分组、资料卡、备注/标签、新好友请求。
- 群管理和群系统事件。
- 历史消息归档与导出。
- 朋友圈相关操作、转发与定时任务。
- 媒体、表情、语音、音色/参考音频、OCR、音频设备及依赖诊断。

部分入口会根据当前装配状态显示未支持、待验证或依赖缺失，请以实际状态和配置支持为准。

## 配置与授权

- 模型网关配置和连通检查、表达规则、模型用量和预算相关管理。
- 本地数据备份、恢复副本校验、账号与窗口状态查看。
- 成员、角色、权限相关实现；多人部署需专门确认，当前密钥登录默认关联本地工作区账号。
- 单密钥登录，1天/1年签发选项，生成时起算，到期会话失效。无机器绑定、在线撤销或抗本机改时钟保证。

## 使用前的核对

以安装指南和 Release 说明为准，确认运行环境、微信适配、模型及读取器配置。软件不是微信官方产品，不承诺防封号、零误发、所有微信版本通用或无人值守已完整验收。
