# 安装与开始使用

## 下载哪一个文件

前往 [Releases](https://github.com/Beritwu/weixin-sales-workbench/releases)，选择最新 **Pre-release / 预览版**中的 `WeixinSalesWorkbench-Setup-*.exe`。GitHub 自动生成的 “Source code (zip/tar.gz)” 仅包含本展示仓库文档，不是软件安装包。

安装包附带 `SHA256SUMS.txt`。在 PowerShell 中可使用 `Get-FileHash .\安装包文件名.exe -Algorithm SHA256` 核对哈希。

## 环境准备

- Windows x64 桌面环境。微信操作需要交互桌面、已登录的兼容微信客户端。
- 安装包及启动检查会说明所需的 Node.js、PowerShell、WebView2 和 .NET 运行环境；不要把安装包下载成功视为全部依赖已经就绪。
- 真实微信控制、历史读取器与 AI 模型需要配置。历史读取依赖可用的本地数据库读取配置；安装包不会携带分发者的微信数据库或解密缓存。
- AI 功能需要可用的模型网关地址、模型及访问凭据。模型服务费用与供应商政策以你自己的服务为准。

**默认运行方式和本版本验证范围，以该 Release 的说明为准。** 如界面显示模拟模式，它不代表已经连接你的真实微信。请先微信联系分发者完成适配。

## 首次使用

1. 加产品主页微信，说明电脑环境与用途，获取试用或购买信息。
2. 安装到正常使用目录；已有版本应沿用原目录更新，先备份数据。
3. 启动工作台，粘贴分发者提供的登录密钥。
4. 进入设置，核对模型、微信连接和数据读取配置。
5. 在“自动化”中获取记录，生成并修改人格、聊天对象画像。
6. 先核对原文与草稿效果。确认环境和目标绑定前，不要启用真实自动发送。

## 更新与退出

关闭工作台后等待它停止自己启动的后台服务，再进行更新。不会要求你通过结束微信客户端来完成正常退出。当前版本修复了退出时运行端收尾与界面线程互相等待的问题。

如果再次启动仍提示已有实例，保留错误代码并联系支持，不要自行删除数据库或所有锁文件。卸载、删除工作区、覆盖配置前先备份自己的记录。
