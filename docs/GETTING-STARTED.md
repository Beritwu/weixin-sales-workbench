# 安装与开始使用

## 准备好这三项

- 一台 Windows x64 电脑，已登录自己的桌面微信。
- 分发者提供的工作台登录密钥。扫码联系 [阿西达卡](../README.md#试用与购买) 申请试用或购买。
- 自己的模型网关地址与访问密钥，用于 AI 总结和试答。

## 下载并登录

下载 [0.2.13 Windows 安装包](https://github.com/Beritwu/weixin-sales-workbench/releases/download/v0.2.13/WeixinSalesWorkbench-Setup-0.2.13.exe)，按安装向导完成安装，然后输入登录密钥。

安装包约 624 MB，已包含所需运行组件，安装后文件约占 1.6 GB。请为安装临时文件和自己的聊天数据另留空间。GitHub 下载区请选择 `.exe` 安装文件；Source code 压缩包是展示仓库文档。

首次登录进入连接引导。以后可从 **设置 → 连接与首次使用** 再次打开。

## 1. 连接微信

打开并登录电脑微信，点击 **发现微信账号**。单账号会自动连接，多账号首次连接时选择要使用的账号。

看到“已发现微信账号与窗口”即可继续。若提示窗口尚未关联，打开微信主聊天窗口后再次发现。微信在托盘时，可从微信账号设置进入窗口与托盘操作。

## 2. 选择 AI 模型

1. 填写本机模型网关地址，例如 `http://127.0.0.1:8990`。
2. 填写网关提供的访问密钥。已经保存过的密钥会自动沿用，输入框留空即可。
3. 点击 **获取模型**，在列表中选择要使用的模型。
4. 点击 **保存模型配置**，新配置立即生效。
5. 点击 **测试模型回复**，查看模型返回的测试文本。

**登录密钥**用于进入工作台，**网关密钥**用于调用模型，两者分别填写在对应位置。模型服务与用量由自己的网关提供。

## 3. 获取聊天并生成总结

1. 在“聊天记录与学习”中确认本机读取，点击 **初始化本机聊天读取**，等待完成。
2. 打开左侧 **自动化**，点击 **获取微信聊天记录**。
3. 点击 **生成人格**，整理自己的语气、措辞与回应习惯。
4. 选择聊天对象，点击 **用户画像**，整理对方的情况、关切与待办。
5. 查看原文、编辑总结，点击 **保存调整**，再使用 **试答**查看回复效果。

读取密钥保存在本机，初始化针对微信 4.x。已有读取缓存可在展开项中导入；自定义数据目录也在该处设置。

聊天学习处理电脑中已保存的一对一文本。每次总结选取最近 160 条文本；要整理手机上的聊天，可先同步到电脑。云端 AI 会处理本次选中的消息和上下文。

## 日常使用与更新

自动回复默认关闭。你可以从资料整理和试答开始，在设置中选择回复方式与自动化规则。顶部可查看状态，必要时使用暂停或紧急停止。

更新时先关闭工作台，再运行新版安装包并沿用原目录。已有数据、账号和模型配置会保留。退出工作台后，其后台服务会一起结束，微信可以继续使用。

## 安装提示与帮助

安装包暂未数字签名。如果 Windows 显示“未知发布者”，请先核对本仓库下载地址与发布页的 `SHA256SUMS.txt`。PowerShell 校验命令为：

```powershell
Get-FileHash .\WeixinSalesWorkbench-Setup-0.2.13.exe -Algorithm SHA256
```

需要配置协助、微信版本适配或遇到错误提示时，添加 [主页微信](../README.md#试用与购买)，发送软件版本和错误提示即可。
